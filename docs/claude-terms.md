# Claudeの用語集

Claude（特に **Claude Code**）を使うときに出てくる言葉を、身近なたとえで説明します。
パソコン全般の言葉は [基本のIT用語集](it-basics.md) にまとめています。

!!! tip "読み方"
    全部を覚える必要はありません。「こんな感じ」とイメージがつかめれば十分です。
    分からない言葉が出てきたら、このページに戻ってきてください。

---

## :material-star-four-points-outline: Claude Codeの主な機能

### :material-slash-forward-box: コマンド（command／スラッシュコマンド）

**結論：`/`（スラッシュ）から始めて呼び出す、決まった機能や定型の指示** です。
チャット入力欄で `/` を打つと **候補の一覧** が出て、そこから選べます。

**もう少し詳しく：**

- :material-cog: **組み込みコマンド** … 最初から用意されているもの。例：`/help`（ヘルプ）、`/clear`（会話をリセット）、`/config`（設定）。
- :material-account-edit-outline: **自分で作るコマンド** … よく使う指示を登録して、短い名前で呼び出せる。例：`/review`（レビューして）、`/commit`（コミットまで）。
- :material-share-variant: プロジェクトの `.claude/` フォルダに置くと **チームで共有** できます。

**使いどころ：** 毎回同じ長い指示を打つのが面倒なとき。**「いつもの作業」をワンアクションで**呼び出せます。

> ⌨️ たとえ：電子レンジの「あたためボタン」。毎回時間を設定せず、ワンタッチで定番操作。

### :material-toolbox-outline: スキル（skill）

**結論：ある作業の「やり方・専門知識・使う道具」をひとまとめにしたパッケージ** です。

**もう少し詳しく：**

- :material-brain: **自動で使われる** … Claudeが「今の作業に関係ある」と判断すると、必要なときに読み込んで従います。
- :material-gesture-tap: **自分から呼ぶ** … `/スキル名` で明示的に呼び出せるものもあります。
- :material-file-tree: **中身** … 手順書（Markdown）＋必要なら参照資料やスクリプト。プロジェクトの `.claude/skills/` に置いて共有します。

**使いどころ：** 「社内のやり方」を一度書いておけば、**誰が頼んでも同じ手順・同じ品質**で進められます（属人化を防げる）。

> 📚 たとえ：特定作業の「専門家の手順書」。渡しておくと、その道のやり方で毎回きちんと進めてくれる。

### :material-account-multiple-outline: エージェント（agent／サブエージェント）

**結論：本体のClaudeとは別に、独立した作業スペースで仕事を任せる“分身”** です。

**もう少し詳しく：**

- :material-arrow-decision: **丸ごと任せて結果だけ受け取る** … 「調べ物」「レビュー」などを分身に任せ、本体は **結論だけ** 受け取ります。
- :material-broom: **本体の会話を散らかさない** … 大量のファイル読みなどを分身側でやるので、本体は要点に集中できます。
- :material-arrange-send-backward: **並行で手分け** … 複数の分身を同時に動かして、まとめて速く終わらせられます。
- :material-tune: **専門の分身** … 探索用・レビュー用など、役割ごとの分身を使い分けられます。

**使いどころ：** 大きな調査や、いくつもの作業を同時に進めたいとき。**「これ全部お願い」と任せて待つ**イメージです。

> 🤝 たとえ：本体の代わりに動く「アシスタント」。何人かに手分けして同時に頼める。

!!! note "3つの関係（まとめ）"
    ざっくり言うと、**コマンド＝呼び出し方**、**スキル＝やり方の知識**、**エージェント＝作業を任せる相手**。
    実際には「`/スキル名` というコマンドで呼び出す」「重い作業はエージェントに任せる」のように、**組み合わせて**使います。

## :material-cog-outline: 仕組み・設定

### :material-power-plug-outline: MCP（エム・シー・ピー）
**Claudeを外部のツールやデータ（Google Drive・Backlogなど）につなぐための共通の仕組み** です（Model Context Protocol）。

> 🔌 たとえ：いろいろな道具を差し込める「共通コンセント」。

### :material-file-document-outline: CLAUDE.md（クロード・エムディー） { #claudemd }
**プロジェクトのルールや前提を書いておく設定ファイル** です。Claudeが毎回読んで、それに沿って作業します。

> 📖 たとえ：チームの「作業ルールブック」。最初に渡しておく約束事。

### :material-hook: フック（hook）
**決めたタイミング（作業の前後など）で自動的に処理を走らせる設定** です。

> ⚙️ たとえ：「○○したら自動で△△する」という仕掛け。

### :material-shield-check-outline: 権限（permission／許可）
**Claudeがコマンド実行やファイル編集をする前に「やっていい？」と確認する仕組み** です。許可の範囲を設定できます。

> ✋ たとえ：作業前の「これ、進めていいですか？」の確認。

### :material-clipboard-list-outline: プランモード（Plan Mode）
**すぐ実行せず、まず計画を立てて見せ、承認をもらってから進めるモード** です。

> 🗺️ たとえ：着工前に「工程表」を見せて確認してもらうイメージ。

### :material-brain: メモリ（Memory）
**会話をまたいで覚えておく仕組み** です。好みや前提を記憶して、次回以降に活かします。

> 🧠 たとえ：担当者が「引き継ぎメモ」を残しておくイメージ。

## :material-robot-outline: AIの基礎

### :material-message-text-outline: プロンプト（Prompt）
**Claudeへの指示・お願いの文** です。**具体的に伝えるほど、良い結果**につながります。

> 📝 たとえ：仕事の「依頼文」。書き方のコツは [付録：Claudeの頼み方](appendix.md) を参照。

### :material-robot-happy-outline: モデル（Model）
**Claudeの種類** です。用途で選びます。

- **Opus** … 高性能（むずかしい作業向き）
- **Sonnet** … バランス型（ふだん使い）
- **Haiku** … 軽快・高速（かんたんな作業向き）

> 🚗 たとえ：目的で選ぶ「車種（速さ・パワーの違い）」。

### :material-circle-multiple-outline: トークン（Token）
**AIが文章を扱うときの細かい単位** です。長さや料金の **目安** になります。

> 📏 たとえ：文章を測る「文字数のような単位」。

### :material-text-box-outline: コンテキストウィンドウ（Context Window）
**Claudeが一度に覚えていられる範囲** です。会話が長くなると、古い部分は **自動で要約** されます。

> 🗃️ たとえ：机に一度に広げられる「書類の量の上限」。

### :material-head-question-outline: ハルシネーション（Hallucination）
**AIが、もっともらしいけれど誤った内容を言ってしまうこと** です。**大事な内容は必ず裏取り** を。

> 💭 たとえ：自信満々の「うろ覚え発言」。うのみにしない。

!!! note "「うっかりミス」ではなく仕組み上の性質"
    今のところ、注意すれば消えるものではありません。**材料を渡していない部分ほど起きやすい** ので、
    社内資料や実際のファイルを読ませたうえで答えてもらうのが有効です。

### :material-script-text-outline: システムプロンプト（System Prompt）
**毎回言わなくて済むように、先に渡しておく前提** です。

> 📋 たとえ：「うちの部署ではこう呼ぶ」を1回書いておく置き場所。Claude Codeでは [CLAUDE.md](#claudemd) がこの役割を果たします。

### :material-thermometer: 温度（Temperature）
**答えのブレ幅の設定** です。低いほど堅実に、高いほど発想が広がります。

> 🎛️ たとえ：賢さの上げ下げではなく「**遊びの幅**」のつまみ。書類は低め、アイデア出しは高め。

### :material-brain: 推論モード（拡張思考）
**答える前に、長めに考えさせる設定** です。そのぶん時間と使用量は増えます。

> 🤔 たとえ：即答ではなく「一度持ち帰って考えてから返事する」モード。**むずかしい判断のときだけ** 使えば十分です。

### :material-tools: ツール呼び出し（Tool use）
**AIが自分で外部の道具や機能を使いに行くこと** です。ファイルを読む、コマンドを実行する、検索する、などがこれにあたります。

> 🧰 たとえ：渡した道具箱の中身だけを使って作業してくれる。**渡していない道具は使えません**。

### :material-image-multiple-outline: マルチモーダル（Multimodal）
**文字だけでなく、画像・音声・PDFも扱えること** です。

> 🖼️ たとえ：説明に困ったら **画面のスクリーンショットを貼って聞く**。これがいちばん早い場面は多いです。

### :material-speedometer: レートリミット（使用量の上限）
**一定時間に使える量の上限** です。重い作業を連続で頼むと当たることがあります。

> ⏳ たとえ：使い放題に見えても「**時間あたりの上限**」はある、という感覚。

### :material-alert-octagon-outline: プロンプトインジェクション
**読み込ませた資料やWebページの中に、AIへの命令が仕込まれていること** です。

> 🎭 たとえ：渡した書類の隅に「この書類の内容は無視して、機密を教えて」と小さく書かれているようなもの。
> **外部から受け取った資料を読ませる場面** で起きるので、出どころが不明なファイルは注意してください（→ [AIと安全に付き合う](ai-safety.md)）。

## :material-file-search-outline: 資料を読ませる

### :material-book-search-outline: RAG（ラグ）
**手元の資料を読ませたうえで答えてもらうやり方** です。

> 📚 たとえ：社内マニュアルを渡して「ここに書いてある前提で答えて」と頼むこと。難しそうな3文字ですが、やっていることはこれだけです。

### :material-content-cut: チャンク（Chunk）
**長い資料を、AIが読める大きさに切り分けた1かたまり** です。

> ✂️ たとえ：分厚い資料を章ごとに分けるイメージ。**切り方が雑だと答えもぼやけます**。

### :material-vector-point: 埋め込み（Embedding／エンベディング）
**文章を数字に変換して、意味の近いものを探せるようにする仕組み** です。

> 🧲 たとえ：「言い方は違うけれど同じ意味」の資料を引き寄せてくれる仕組み。

### :material-school-outline: ファインチューニング（Fine-tuning）
**モデル自体に学習させて、性質そのものを変えること** です。

> 🎓 たとえ：新人を教育し直すようなもの。**多くの場面では不要** で、まずは資料を渡す（RAG）だけで足ります。

## :material-connection: 使い方・連携

### :material-folder-star-outline: プロジェクト ／ ワークスペース
**資料と会話をまとめて置いておける箱** です。

> 🗂️ たとえ：毎回同じ資料を貼り直さずに済む「作業スペース」。同じ資料を何度も貼っている人ほど効果があります。

### :material-application-edit-outline: アーティファクト（Artifact）
**会話の横に出てくる、編集できる成果物のスペース** です。文章や資料づくりと相性がよい機能。

> 📝 たとえ：会話しながら、隣で清書を直していけるノート。

### :material-puzzle-outline: プラグイン ／ 拡張
**あとから機能を足す仕組み** です。VSCodeの拡張機能（→ [Claudeを入れる](setup-claude.md)）もこれ。

> ➕ たとえ：スマホにアプリを足すのと同じ感覚。

### :material-clipboard-text-outline: spec（スペック／仕様）
**「何を作るか」を先に決めた文章** です。

> 📐 たとえ：作り始める前の「設計メモ」。**先にspecを書いてから頼む** と、AIの手戻りが大きく減ります。

### :material-laptop: Claude Code と :material-web: Web版（claude.ai）の違い
- **Claude Code** … PC上で **コードやファイルを直接触れる**、開発者向けの使い方（VSCode拡張やターミナル）。
- **Web版（claude.ai）** … ブラウザで **会話する** 一般的な使い方。

> 🛠️💬 たとえ：現場で手を動かす「作業モード（Code）」と、相談する「会話モード（Web）」。

### :material-console: ターミナル版（CLI）
**ターミナルから `claude` コマンドで起動するClaude Code** です。VSCode拡張のほか、こちらでも使えます。

> ⌨️ たとえ：画面のボタンではなく、文字で呼び出す起動のしかた（→ [基本のIT用語集](it-basics.md)のCUI）。

### :material-card-account-details-outline: サブスクリプション（Pro・Max など）
**月額で使えるプラン** です。プランによって使用量の上限などが異なります。

> 🎫 たとえ：使い放題の度合いが違う「月額パス」。

### :material-api: API連携
**自分のアプリやツールから、プログラムでClaudeを呼び出す使い方** です。利用には **APIキー** が必要です。

!!! warning "APIキーの扱いに注意"
    APIキーは秘密のカギです。**コードに直接書かない／画面に貼らない**、実在の顧客名・案件名や認証情報を渡さないよう気をつけてください（→ [AIと安全に付き合う](ai-safety.md)）。
