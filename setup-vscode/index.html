    VSCodeを入れる¶

    この章のゴール

    自分のPCに VSCode（ブイエスコード） を入れて、 「ファイルを開いて編集できる」状態になること。

    「準備する」章の進み方¶

    準備は、次の 3ステップ です。1ページずつ進めれば大丈夫です。

    flowchart LR
    A[1.VSCode<br/>作業場所をつくる] --> B[2.Claude<br/>お願いできる相棒]
    B --> C[3.Git / GitHub<br/>履歴とネット上の置き場]
    C --> D([準備完了 🎉])

    なぜこの順番なのか

    先に VSCode → Claude をそろえておくと、そのあとの Git や GitHub の準備を Claudeに日本語で頼んで進められる ようになります。むずかしい作業を後ろに回す作戦です。

    このあとの章では、GitHubの操作を次の 2通り で並べて説明します。好きな方を選んでください。

    • Claudeに頼む … VSCodeの中で、Claudeに日本語でお願いする（コマンド不要）
    • 自分で操作 … 画面のボタンを自分でクリックする

    1. VSCodeとは¶

    VSCodeは、文章やファイルを編集できる無料のソフトです。 このガイドでは「作業する場所」として使います。GitHubとの相性がよく、初心者にもおすすめです。

    VSCodeでできること イメージ
    ファイルを開く・書き換える Wordのような編集画面
    フォルダをまるごと開く 左側にファイル一覧が並ぶ
    変更の履歴を扱う あとで入れる Git と連携する
    AIに頼む あとで入れる Claude が中で動く

    2. インストールする¶

    公式サイト https://code.visualstudio.com を開き、自分のPCに合うボタンから入れます。

    1. 公式サイトの Download for Windows を押す
    2. ダウンロードされたファイル（...User Setup.exe）を開く
    3. 画面の案内に従って「次へ」で進める（途中の同意・追加タスクはそのままでOK）
    4. 完了したらVSCodeを起動する
    1. 公式サイトの Download for macOS を押す
    2. ダウンロードされた .zip を開くと、Visual Studio Code アプリが出てくる
    3. それを アプリケーション フォルダにドラッグして移動する
    4. アプリケーションから起動する

    ボタンの文字はお使いのPCで変わります

    公式サイトは、開いたPCを自動で判別します。上の画像は Mac で開いたときのもので、 Windowsで開くと Download for Windows と表示されます。表示された そのままのボタン を押せばOKです。

    日本語表示にする

    初回起動時に「日本語に変更しますか？」と出たら 「インストールして再起動」 を押すと、メニューが日本語になります。 出なかった場合は、左側の 拡張機能 で Japanese Language Pack を検索して入れれば同じです。

    「発行元」を必ず確認

    拡張機能ストアには、本物に似せた名前のニセ拡張 が混ざることがあります。 検索結果をそのまま押さず、拡張の名前をクリックして詳細ページを開き、次の3点 を確認してください。

    確認すること 正しい状態
    拡張名 Japanese Language Pack for Visual Studio Code
    発行元（Publisher） Microsoft ＋ 青い認証済みバッジ ＋ microsoft.com
    インストール数 1,500万件以上。数百件〜数千件しかないものは疑う

    ひとつでも合わなければ 入れずに閉じてください。似た名前・似たアイコンでも別物です。

    表示が少し違っても大丈夫

    インストール ボタンは、すでに入れたあとは「アンインストール」に変わります。 インストール数（画像では1,531万件）は撮影時点の数値なので、実際の画面では増えています。

    3. 画面の見方（ざっくり）¶

    最初はこの3か所だけ覚えれば十分です。

    flowchart LR
    A[左のアイコン列<br/>ファイル・検索・拡張機能] --> B[中央<br/>ファイルの編集画面]
    B --> C[下のターミナル<br/>文字で指示する場所]
    • 左のアイコン列 … ファイル一覧、 拡張機能（Claudeもここから入れます）
    • 中央 … 実際に文章やコードを書くところ
    • ターミナル … メニューの「ターミナル」→「新しいターミナル」で開く。コマンドを打つ場所です

    ターミナルは怖くない

    ターミナルは「文字で指示を出す窓口」です。このガイドでは、貼り付けるだけの1行しか使いません。 しかも多くの場面は Claudeに頼めば代わりに実行してくれます。

    4. 画面の名前をおぼえる¶

    このガイドや、あとで読む説明では「サイドバー」「パネル」といった 場所の名前 がよく出てきます。 全部おぼえる必要はありません。「そう呼ぶんだな」 くらいで大丈夫です。

    flowchart TB
    subgraph W["VSCodeのウィンドウ"]
        direction LR
        A["アクティビティバー<br/>（左端のアイコン列）"]
        B["サイドバー<br/>（ファイル一覧など）"]
        C["エディター<br/>（書く・読む場所）"]
        A --- B --- C
    end
    W --> D["パネル（ターミナル・問題の一覧）"]
    D --> E["ステータスバー（いちばん下の細い帯）"]
    場所 名前（日本語表示） 何をするところ
    いちばん左のアイコン列 アクティビティバー 表示を切り替えるスイッチ。押すと右のサイドバーの中身が変わる
    その右の細長い欄 サイドバー 選んだアイコンの中身（ファイル一覧・検索結果など）が出る
    中央の広い場所 エディター 実際に文章やコードを書く場所。上のタブで複数のファイルを切り替えられる
    下側の枠 パネル ターミナルやエラーの一覧が出る。使わないときは閉じてOK
    いちばん下の細い帯 ステータスバー いま何のブランチにいるか、エラーが何件あるかなどの状態表示
    右側の欄 セカンダリサイドバー 最初は非表示。チャットなどを置ける予備の欄

    英語表示のままの人へ

    日本語パックを入れていない場合は、それぞれ Activity Bar / Primary Side Bar / Editor / Panel / Status Bar / Secondary Side Bar と表示されます。

    5. アクティビティバーのアイコンの意味¶

    左端に並んでいるアイコンは、サイドバーの中身を切り替えるスイッチ です。 このガイドでよく使うのは の付いた3つだけです。

    アイコン 名前 できること 出番
    エクスプローラー 開いているフォルダのファイル一覧。ファイルを開く・新規作成する よく使う
    検索 フォルダ全体から文字を探す・まとめて置き換える ときどき
    ソース管理 Gitの変更を確認して コミット する。変更した行に色が付く よく使う
    実行とデバッグ プログラムを途中で止めながら中身を調べる 使いません
    拡張機能 機能を追加する。日本語パックもClaudeもここから入れます よく使う
    アカウント（下のほう） GitHubやMicrosoftアカウントへのサインイン状態 ときどき
    管理（いちばん下の歯車） 設定・テーマ・ショートカットの変更 ときどき

    アイコンの数は人によって違います

    拡張機能を入れると、この列にアイコンが増えることがあります。 表示されているアイコンの数がガイドと違っていても問題ありません。

    6. 覚えておくと便利な操作¶

    「メニューのどこにあるか分からない」ときは、コマンドパレット を開いて名前で探すのがいちばん早いです。

    やりたいこと ショートカット
    コマンドパレット（機能を名前で探す何でも窓口） Ctrl+Shift+P
    サイドバーを開く／閉じる Ctrl+B
    ファイルを名前で開く Ctrl+P
    ターミナルを開く／閉じる メニューの ターミナル → 新しいターミナル
    やりたいこと ショートカット
    コマンドパレット（機能を名前で探す何でも窓口） Cmd+Shift+P
    サイドバーを開く／閉じる Cmd+B
    ファイルを名前で開く Cmd+P
    ターミナルを開く／閉じる メニューの ターミナル → 新しいターミナル

    迷ったらコマンドパレット

    コマンドパレットを開いて、やりたいことを日本語で打ち込む（例：ターミナル）と、 候補が絞り込まれます。メニューを探し回らなくて済む ので、最初に覚えると楽になります。

    もっと詳しく知りたいとき

    VSCode公式の画面説明ページ（英語）にすべて載っています。 VS Code User Interface（公式ドキュメント）
